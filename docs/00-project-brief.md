# Project Brief

## Problem and solution

Personal memories are often disconnected from place. GeoDiary lets a signed-in person attach text, date, and an optional photo to a selected map point, then revisit private entries as a list or map.

## Users, scope, and features

The target is an individual diary keeper. Scope includes Google sign-in, Mongo-backed sessions, create/list/map/detail/edit/delete, GeoJSON points, optional images, validation, and ownership isolation. The stack is Node/Express/Pug, Passport, Mongoose/MongoDB Atlas, Mapbox, and Multer.

## Educational goals

An intern practices requirements-led MVC, authentication versus authorization, safe uploads, geospatial data, server rendering, automated tests, ADRs, and traceability.

## Out of scope

Sharing, social features, native apps, offline sync, collaborative editing, custom identity, geocoding, production object-storage implementation, and complex infrastructure are excluded.
